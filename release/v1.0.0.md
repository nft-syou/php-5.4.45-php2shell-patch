This release provides the reviewed PHP 5.4.45 source backport for
CVE-2026-109618 and CVE-2026-109619.

### Assets

- `php2shell-mitigation-for-php-5.4.45-source.tar.gz` contains the official
  PHP 5.4.45 source with the mitigation patch already applied. It is a source
  distribution, not a prebuilt PHP runtime package, and preserves upstream
  test fixtures.
- `php-5.4.45-php2shell.patch` applies directly to the official PHP 5.4.45
  source with `patch -p1`.
- `SHA256SUMS` verifies both source artifacts.

The patched-source archive is reproducible. Its exact contents were built
with AddressSanitizer and passed the OOM, allocation-overflow, cross-request,
session upload-progress, and multipart body-part regression checks. The patch
was also compiled and tested with Visual C++ 2008 SP1 (VC9); see the README for
the complete PHPT results and limitations.

This is an unofficial backport and does not restore general security support
for PHP 5.4.
